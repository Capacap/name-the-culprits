# Fonts

The site's four faces, Cinzel, Libre Caslon Text, Playfair Display and
Grenze Gotisch, as the WOFF2 files Google Fonts serves for their Latin and
Latin Extended ranges, unchanged. `../fonts.css` declares them.

Each is licensed under the SIL Open Font License, Version 1.1. `OFL.txt`
holds the licence and each family's copyright notice as its files give it,
and the site serves it beside the fonts.
